# 局域网云盘

一个跑在自己电脑上的私有云盘：后端 FastAPI，前端原生 HTML/CSS/JS，无需数据库、无需构建。
同一 WiFi 下的手机、平板、其他电脑打开浏览器就能传文件、看照片、放视频、写 Markdown 笔记。

## 快速开始

**Windows**：双击 `启动云盘.bat`

**macOS / Linux**：

```bash
pip install -r requirements.txt
python main.py
```

启动后终端会打印本机地址、局域网地址，以及一个可以直接用手机扫的二维码：

```
本机访问 : http://127.0.0.1:8088
局域网   : http://192.168.2.79:8088
```

手机连同一个 WiFi，扫码或输入局域网地址即可。首次在 Windows 上启动时如果弹出防火墙提示，
勾选「专用网络」并允许，否则手机连不上。

## 命令行参数

```bash
python main.py --port 9000            # 换端口
python main.py --password 123456      # 开启访问口令
python main.py --root D:/共享/网盘     # 换存储目录（默认 ./storage）
python main.py --notes D:/共享/笔记    # 换笔记目录（默认 ./notes）
```

也可以用环境变量：`LAN_DISK_PORT`、`LAN_DISK_PASSWORD`、`LAN_DISK_ROOT`、`LAN_DISK_NOTES`。

## 功能

- **上传**：点按钮选文件，或直接把文件和文件夹拖进窗口；拖到某个文件夹卡片上就传进那个文件夹
- **下载**：单文件直下；文件夹自动打包成 zip；多选后可一次性打包
- **预览**：图片、视频（支持拖动进度条，走 HTTP Range）、音频、PDF
- **音频播放**：内置播放器，能读 MP3 的 ID3 标签显示歌名/艺人/专辑并展示内嵌封面；wav/flac/m4a/aac 同样可以直接播放
- **Word / Excel / PPT**：.docx 按纸张排版还原标题层级、粗斜体下划线、颜色、列表、表格、图片、超链接；
  .xlsx 支持多工作表切换、合并单元格、列字母与行号、冻结表头、日期与百分比格式；
  .pptx 把每页渲染成 16:9 幻灯片，保留标题、多级项目符号、图片、表格与页面背景色
- **Markdown**：渲染成带样式的文档（标题、列表、表格、代码块、引用、图片），相对路径的图片能正常显示
- **HTML**：在沙箱 iframe 里直接跑起来，样式、脚本、相对引用的图片都正常；也可一键在新窗口打开
- **CSV / TSV**：自动识别分隔符，渲染成带行号、可横向滚动的表格，引号内的逗号换行都按规范处理
- **压缩包**：zip / tar / tar.gz 点开直接看内容清单 —— 按目录层级缩进，显示每个文件的大小和修改时间；
  中文文件名不乱码（自动识别 UTF-8/GBK）；「解压到当前文件夹」一键解开（自动防 zip slip 路径攻击、
  跳过软链接，解压总量超 2GB 自动中止）；加密压缩包能看到清单但提示无法在线解压；
  单文件 .gz/.bz2/.xz 显示内含的文件；rar、7z 没有标准库支持，提示下载后用本地工具解压
- **纯文本**：txt/json/代码等按等宽字体展示，可在线编辑并保存
- **移动文件**：点卡片上的「移动到」在文件夹树里选目标；也可以直接把文件拖到某个文件夹卡片上
- **网络笔记**：侧边栏「笔记」是一个 Markdown 笔记本 —— 左列笔记列表（置顶/搜索），右侧边写边预览。
  停手 0.9 秒自动保存，`Ctrl+S` 手动存；带 H1-H3、粗斜体、代码、列表、待办、引用、链接、表格的工具栏；
  图片可以直接 `Ctrl+V` 粘贴或拖进编辑区（存进 `notes/media/`，按内容哈希去重）；单篇可导出为 `.md`，
  `GET /api/notes/export` 还能把所有笔记打包成 zip 备份
- **管理**：新建文件夹、重命名、删除、批量删除、搜索（递归全盘）、按名称/时间/大小排序
- **文件备注**：卡片/列表操作菜单里的「备注」按钮给任何文件或文件夹写说明（最多 2000 字）；
  有备注的文件名称旁会一直挂一个黄色小气泡角标，鼠标放上去直接看内容；文件被重命名、
  移动（含整个文件夹里的所有备注）时自动跟着走，删除时一并清理，存在 `remarks.json`
- **分享链接**：卡片上的链接按钮（或多选后的「分享链接」）会给文件生成一个短地址，
  形如 `http://192.168.1.9:8088/s/AbC123xyz` —— **同一 WiFi 下谁拿到链接都能直接打开**，
  不需要口令也不用登录。链接可以一键复制、扫码（内置二维码）、设有效期（1/7/30 天或永久）、
  勾选「打开就直接下载」；多选分享会打包成一个 zip。随时可以「取消分享」让链接立刻失效
- **我的分享**：侧边栏「我的分享」列出所有创建过的链接 —— 谁（哪个文件）、什么时候建的、还剩几天、
  被打开过几次；在这里直接复制、在新窗口打开、改有效期（1/7/30 天 / 永久）、取消分享。
  侧栏角标是当前有效链接数，过期的排在最后并标灰
- **分类**：侧边栏「最近使用 / 图片 / 视频 / 音乐 / 文档」快速筛选
- **存储**：侧边栏显示磁盘占用与剩余空间
- **系统设置**：侧边栏最下面是「系统设置」，分两页 ——
  **关于我们**（版本、运行时长、服务地址、Python/FastAPI 版本、目录位置、文件与笔记统计、磁盘占用、快捷键），
  **系统日志**（上传/下载/重命名/移动/删除/写笔记/登录等操作自动记录，按级别筛选、关键词搜索、导出 txt、清空）
- **适配**：手机、平板、桌面自适应；深色模式；键盘 `/` 聚焦搜索、Esc 关闭、Delete 删除选中项

## 笔记是怎么存的

笔记不放在 `storage` 里，而是单独一个目录（默认 `./notes`），免得和文件浏览混在一起：

```
notes/
├── <12位id>.json      每篇笔记：标题、正文、创建/更新时间、是否置顶
└── media/<哈希>.jpg   笔记里粘贴的图片，按内容 sha1 命名，同一张图不会重复存
```

写入走「临时文件 + `os.replace`」的原子替换，断电不会留下半截文件；整个 `notes` 目录直接复制走就是完整备份。
标题留空时，列表里会自动取正文第一行（去掉 `#`、`-` 之类的标记）当标题，所以随手写也能有个像样的名字。

## Office 预览是怎么做的

`.docx / .xlsx / .pptx` 本质都是 ZIP + XML，所以后端用标准库 `zipfile` + `xml.etree` 直接解析
（见 `office.py`），**不需要装 Office、WPS，也不需要 python-docx / openpyxl / python-pptx**，
断网也能用。内嵌图片通过 `/api/office_media` 从压缩包里按需取出。

局限：

- 只支持 2007 之后的 OOXML 格式。`.doc / .xls / .ppt / .wps / .et / .dps` 是二进制老格式，无法在线解析，
  会提示下载 —— 用 Office 另存为新格式即可预览
- 版式是「内容还原」而不是「像素还原」：分栏、文本框浮层、艺术字、动画、SmartArt 这些不会还原
- Excel 单表最多渲染 2000 行 × 80 列，超出会提示下载查看；Office 文件超过 60MB 不做在线解析
- 幻灯片正文过长时，正文区内部滚动，不会截断内容

## 系统日志是怎么记的

日志不写数据库，也不占内存不放：`journal.py` 同时做两件事 ——

- 进程内存里留最近 **2000 条**（`deque`），筛选、搜索、分页都走内存，翻页不用扫磁盘
- 每条记录再追加写一行 JSON 到 `logs/system.log`，服务重启后从文件尾部恢复，日志不会因为重启清零
- 单文件超过 **2MB** 自动轮转成 `system.log.1`（只留一代），不会无限长大

每条记录长这样，前端拿到的就是这个结构：

```json
{"id": 42, "ts": 1762478345.12, "level": "warn", "action": "delete",
 "message": "删除 1 项", "detail": "项目资料（文件夹） · 释放 1.5 MB", "ip": "192.168.2.31"}
```

级别有四档：`info`（普通）、`ok`（成功）、`warn`（警告，如删除、口令错误、4xx 请求）、`error`（异常/5xx）。
会记录的动作用一句话概括：上传、下载、打包、新建文件夹、重命名、移动、复制、删除、保存文本、
笔记的新建/插图/导出/删除、登录成功与失败、日志的清空与导出、服务启动与停止，
以及所有出错的 API 请求（正常浏览不会刷屏，`/static` 和 401 都被排除）。

日志文件本身在 `lan-disk/logs/` 下，**不在 `storage` 里**，所以文件浏览里看不到、也删不掉。
不想留痕直接把 `logs/` 整个删掉即可，下次启动会重新建。

## 分享链接是怎么做的

分享不等于把口令给出去。点「分享」时后端会生成一个随机 token（`secrets.token_urlsafe`，12 个字符），
记录写进 `shares.json`，链接就是 `/s/<token>`：

- **谁都能打开**：`/s/<token>` 走的是独立的公开路由，不校验口令 Cookie —— 否则收到链接的人还要问你要密码。
  其它接口依然需要登录，分享只放行被分享的那几个文件
- **只读**：分享页只能看和下载，不能上传、删除、改名字
- **能收回来**：设了有效期的到点自动失效；随时点「取消分享」立刻删记录，链接马上 404
- **文件删了链接就废**：每次访问都会重新确认目标还在，文件被删或改名会返回一张「内容已被删除」的页面
- **范围**：单文件按类型决定内联预览还是直接下载（图片/音视频/PDF/文本直接打开，其它下载），
  文件夹和多选一律打包成 zip
- **可扫**：`/api/qr?text=` 用 `qrcode` 现画二维码（没装这个库就自动隐藏二维码那块），手机上扫码就能拿

链接用的是**本机的 192.168 网段地址**（`lan_ips()` 里排过序，不会给你一个虚拟网卡或 127.0.0.1），
所以发给别人时不用手动改 IP。同一个 token 反复分享同一个文件会复用旧链接，不会堆一堆没用的记录。

## 安全说明

这是**局域网内**使用的工具，默认不设口令，局域网内任何人知道地址就能读写。

**开关密码登录不用改命令行**：进入「系统设置 → 登录安全」，打开「需要密码登录」开关、
设置口令、保存即可；关闭也是在这里一键搞定。设置保存在 `security.json`，重启后依然生效。
开启后局域网内其他设备需要用新口令重新登录，当前浏览器保持登录；分享链接不受影响，照常打开。
忘记口令时，删除 `security.json` 并重启云盘即可恢复无密码访问。

也可以在启动时直接指定口令（不写 `security.json`，UI 设置过之后则以 UI 为准）：

```bash
python main.py --password 你的密码
```

其它要点：

- 所有路径都做了目录穿越拦截，无法通过 `../` 访问 `storage` 之外的文件
- HTML 预览运行在 `sandbox` iframe 里（不给 `allow-same-origin`），页面脚本读不到本盘的口令 Cookie、也无法直接调用接口；点「在新窗口打开」则是完整同源打开，只对自己信任的网页这样做
- 口令通过 HttpOnly Cookie 保存，有效期 30 天
- **分享链接就是一把钥匙**：拿到链接的人不需要口令，链接在有效期内一直能用。设个有效期、
  用完点「取消分享」，不要把链接发到群里/公网。`shares.json` 里存的是明文 token，删掉这个文件等于全撤
- 服务监听 `0.0.0.0`，仅建议在可信网络中运行；不要把端口映射到公网

## 目录结构

```
lan-disk/
├── main.py            # 后端：全部接口 + 启动入口
├── office.py          # docx/xlsx/pptx 解析（纯标准库）
├── audiotag.py        # 读 MP3 的 ID3 标签与封面
├── notes.py           # 网络笔记存储（Markdown + 图片附件）
├── journal.py         # 系统日志（内存缓冲 + JSONL 落盘）
├── archives.py        # 压缩包预览与解压（zipfile/tarfile，防 zip slip、限 2GB）
├── remarks.py         # 文件备注（remarks.json，重命名/移动/删除时自动同步）
├── shares.py          # 分享链接（token + 有效期，存 shares.json）
├── static/
│   ├── index.html     # 页面骨架
│   ├── style.css      # 样式（浅色/深色）
│   └── app.js         # 交互逻辑
├── storage/           # 文件实际存放位置（demo/ 是示例，可删）
├── notes/             # 笔记存放位置（首次启动自动创建）
├── logs/              # 系统日志（自动创建，可随时删）
├── shares.json        # 分享链接记录（删掉 = 所有链接立即失效）
├── requirements.txt
└── 启动云盘.bat / start.sh
```

## 主要接口

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/list?path=` | 列目录（含面包屑） |
| GET | `/api/browse?kind=` | 按类型浏览：recent/image/video/audio/doc |
| GET | `/api/search?q=` | 递归搜索 |
| POST | `/api/upload` | 上传（multipart，字段 `path` + `files`） |
| POST | `/api/mkdir` | 新建文件夹 |
| POST | `/api/rename` | 重命名 |
| POST | `/api/move` / `/api/copy` | 移动 / 复制 |
| POST | `/api/delete` | 删除（支持批量） |
| GET | `/api/download?path=` | 下载（文件夹自动打包） |
| POST | `/api/zip_many` | 多选打包下载 |
| GET | `/api/raw?path=` | 原始内容（支持 Range，用于预览） |
| GET | `/api/text` · POST `/api/save_text` | 读取 / 保存文本文件 |
| GET | `/api/office?path=` | 解析 Office 文件，返回前端可渲染的结构 |
| GET | `/api/office_media?path=&name=` | 取 Office 文件里内嵌的图片 |
| GET | `/api/audio_meta?path=` | 读音频 ID3 信息（歌名/艺人/专辑/封面有无） |
| GET | `/api/audio_cover?path=` | 取音频内嵌封面 |
| POST | `/api/share` | 创建分享（`paths`、`days`、`label`） |
| GET | `/api/shares` | 现有分享列表 |
| POST/DELETE | `/api/share/<token>` | 改有效期 / 取消分享 |
| GET/POST | `/api/security` | 读 / 设置口令开关（`enabled`、`password`） |
| GET | `/s/<token>` | 公开访问入口（无需登录，`?dl=1` 强制下载） |
| GET | `/api/qr?text=` | 生成二维码 PNG |
| GET | `/api/tree` | 文件夹树（移动时选目标） |
| GET | `/api/notes?q=` | 笔记列表（置顶优先，按更新时间倒序，`q` 搜标题+正文） |
| POST | `/api/notes` | 新建笔记 |
| GET/POST/DELETE | `/api/notes/<id>` | 读取 / 保存 / 删除单篇笔记 |
| POST | `/api/notes/<id>/pin` | 置顶 / 取消置顶 |
| POST | `/api/notes/media` | 上传笔记图片（multipart，字段 `file`） |
| GET | `/notes-media/<文件>` | 取笔记图片 |
| GET | `/api/notes/export` | 全部笔记打包成 zip（每篇一个 .md） |
| GET | `/files/<相对路径>` | 按真实路径提供文件（HTML 预览用，保证相对资源可解析） |
| GET | `/api/stats` | 占用统计 |
| GET | `/api/about` | 关于页数据：版本、运行时长、目录、内容统计、磁盘 |
| GET | `/api/logs?level=&q=&limit=&offset=` | 系统日志（级别筛选、关键词、分页） |
| DELETE | `/api/logs` | 清空系统日志 |
| GET | `/api/logs/export` | 导出系统日志为 txt |
